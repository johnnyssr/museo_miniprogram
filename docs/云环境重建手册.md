# 云环境重建手册（腾讯云 CloudBase / 微信云开发）

> 用途：当云开发环境被删除、或需要在一个全新的腾讯云账号 / 环境上从零搭起时，照此操作。
> 本项目三端（小程序、公网后台、本地后台）共用**同一个云环境**，环境 ID 一变，多处都要跟着改。
>
> 示例值：当前环境 ID `beibuwan-d8gx5w5nka63192ae`，地域 `ap-shanghai`。下文凡出现 `<新环境ID>` / `<地域>` 处替换为你的实际值。

---

## 0. 环境依赖地图（改之前先理解）

| 模块 | 位置 | 依赖云环境的点 |
|---|---|---|
| 小程序 | `miniprogram/app.ts` | `wx.cloud.init({ env })` |
| 后台默认值 | `admin/src/config.ts` | `CLOUD_ENV` / `CLOUD_REGION` |
| 后台本地覆盖 | `admin/.env.local`（不入库） | `VITE_CB_ENV` / `VITE_CB_REGION` |
| 文档示例 | `README.md` | `.env.local` 示例片段 |
| 操作手册生成脚本 | `docs/gen_manual.py` | `ENTRY_URL`（静态托管域名，部署后才知道） |
| 云函数 | `cloudfunctions/getExhibits`、`getExhibitQRCode` | 要重新部署到新环境 |
| 数据库集合 | 代码引用 `exhibits`、`media` | 要重建 + 配安全规则 |
| 云存储 | `admin/src/cloudbase.ts`（uploadFile 等） | 旧文件随库一起丢失，需重传 |
| 后台登录 | `admin/src/cloudbase.ts` `signInWithPassword` | 要开通登录方式 + 建账号 |

> ⚠️ **数据与媒体无法恢复**：库被删后，展品数据和上传到云存储的图片/音视频都没了，只能重建；用外部 http 链接的媒体不受影响。

---

## 1. 拿到新环境 ID

微信开发者工具点「云开发」→ 用小程序账号开通/进入新环境 → 控制台「环境 → 环境信息」，记下**环境 ID** 和**地域（region）**。后面每一步都要用。

---

## 2. 改代码（4 处 env ID）

把下面 4 处的旧环境 ID 全部替换为 `<新环境ID>`（region 不是 `ap-shanghai` 时一并改）：

1. `miniprogram/app.ts` — `wx.cloud.init({ env: '<新环境ID>' })`
2. `admin/src/config.ts` — `CLOUD_ENV` 默认值、`CLOUD_REGION` 默认值
3. `admin/.env.local` — `VITE_CB_ENV` / `VITE_CB_REGION`（本文件不入库，须本机手动改）
4. `README.md` — `.env.local` 示例片段（保持一致，非功能性）

全仓库自查有无遗漏：

```bash
grep -rn "<旧环境ID>" . | grep -v node_modules | grep -v "\.git/"
```

> `docs/gen_manual.py` 的 `ENTRY_URL` 也含旧环境 ID，但它是**静态托管域名**，要等第 8 步部署后拿到新域名再改（见第 9 步）。

---

## 3. 建数据库集合

微信开发者工具「云开发」控制台（确认左上角是新环境）→「数据库」→ 新建两个集合（名字须完全一致、全小写）：

- `exhibits`（展品数据）
- `media`（媒体库记录）

---

## 4. 配集合安全规则（两个集合都要）

每个集合 →「权限设置 / 数据权限」→ 选「**自定义安全规则**」→ 点「修改」填入并保存：

```json
{
  "read": true,
  "write": "auth != null"
}
```

含义：游客（小程序）可读，仅登录用户（后台维护者）可写。`exhibits` 和 `media` 都要填。

---

## 5. 部署云函数

微信开发者工具代码界面，确认 `cloudfunctions` 目录已关联新环境（否则右键目录「切换云开发环境」）：

1. 右键 `cloudfunctions/getExhibits` →「上传并部署：云端安装依赖（不上传 node_modules）」。
2. 右键 `cloudfunctions/getExhibitQRCode` 同样操作。

> 右键无此菜单：重启开发者工具，让它重新识别 `cloudfunctionRoot`。

---

## 6. 配 `getExhibitQRCode` 环境变量 + 关 IP 白名单

> 不配这步只影响「后台生成展品小程序码」，其它功能正常，可最后补。

1. 控制台「云函数」→ `getExhibitQRCode` →「环境变量」新增：
   - `WX_APPSECRET` = 小程序 AppSecret（微信公众平台「开发管理 → 开发设置」里查，**必填，勿写进代码**）
   - `WX_APPID` 可选（缺省用代码内默认 AppID）
2. 微信公众平台「开发管理 → 开发设置」确认 **access_token 的 IP 白名单未启用**（云函数出口 IP 不固定，启用会导致换 token 失败）。

---

## 7. 开通后台登录 + 建维护者账号

后台用用户名密码登录。腾讯云 CloudBase 控制台「身份认证」：

1. 「登录方式」→ 启用「**用户名密码**」。
2. 「管理 → 用户管理」→「新建用户」，给每个维护者建**用户名 + 密码**。
3. 自己先建一个，用于后续验证。

> 不开通登录方式 / 不建账号，后台登录不了、也写不进数据。

---

## 8. 本地验证 + 部署公网后台

### 8.1 本地验证
```bash
cd admin
npm install     # 首次或换机时
npm run dev     # 默认 http://localhost:5173（被占用会自动换 5174 等）
```
浏览器打开，用第 7 步的账号登录：能登进去、展品列表能加载（空的也算通），说明**数据库 + 登录 + 读云函数**链路 OK。

### 8.2 打包并部署到静态托管
```bash
cd admin
npm run build   # 产物在 admin/dist/（index.html + assets/）
```
验证新环境 ID 已编译进产物、旧 ID 零残留：
```bash
grep -ro "<新环境ID>" admin/dist/ | wc -l   # 应 >=1
grep -ro "<旧环境ID>" admin/dist/ | wc -l   # 应为 0
```
CloudBase 控制台 →「静态网站托管」→「网站部署」→「本地项目部署 → 本地项目上传」，按下表填：

| 字段 | 填写 | 说明 |
|---|---|---|
| 项目文件类型 | 文件夹 | 选本机 `admin/dist` |
| 项目名称 | 自定义（如 `museo`） | 仅应用名，不影响访问路径 |
| **安装命令** | **留空** | 传的是成品，跑 `npm install` 会失败 |
| **构建命令** | **留空** | 别点「一键填写」（会自动填回 install/build） |
| **构建产物目录** | `./` | `index.html` 就在上传内容最外层 |
| 部署路径 | `/` | 根路径；子路径会导致 `/assets/...` 白屏 |

部署成功后在「部署版本」拿到访问域名，形如 `https://<项目名>-<新环境ID>.webapps.tcloudbase.com/`。

**后续更新后台代码**：重新 `npm run build`，在该应用点「更新版本」重传 `admin/dist`（配置同上）。只改数据不用重新部署。

---

## 9. 更新操作手册里的后台域名

拿到第 8.2 的新域名后，改 `docs/gen_manual.py` 的 `ENTRY_URL` 为新域名（形如 `https://<项目名>-<新环境ID>.webapps.tcloudbase.com/#/exhibits`），再按需重新生成手册。

---

## 10. 录入展品数据

库是空的，三种方式任选：

- **表单**：后台「展品管理 → 新增展品」，逐条填。
- **CSV 批量导入**：后台「批量导入 → 下载模板」，列为 `exhibitId, name, summary, text, image, audioUrl, videoUrl`（`image` 列多张用 `|` 分隔），填好上传，页面会校验+查重。
- **脚本批量插入**：见文末附录。

媒体（图片/音视频）在「媒体库」上传，或在展品里直接填外部链接。

---

## 11. 小程序重新发布（关键，别漏）

环境 ID 写死在小程序代码里，**线上正式版跑的是上次发布的旧代码（旧环境已删）**，不会自动用新代码。必须：

1. 开发者工具**先用「开发版」自测**：首页能加载展品、详情正常 → 说明小程序连新环境 OK。
2. 右上角「**上传**」新版本。
3. 微信公众平台「版本管理 → 开发版本」→「**提交审核**」。
4. 审核通过后「**发布**」。

> 有「体验版」在用的话，同样要重新上传设为体验版。审核期间线上仍是旧版（连旧环境、加载不出数据），尽早提交。

## 附录：Node 批量插入展品脚本

`@cloudbase/js-sdk` 本是浏览器 SDK，在 Node 里跑需补 `localStorage` / `window` / `XMLHttpRequest` 垫片（登录走 fetch，数据库走 XHR）。下面脚本登录后幂等插入展品，可重复运行。

**用法**（在 `admin/` 目录下，依赖其 `node_modules`）：
```bash
cd admin
CB_ENV='<新环境ID>' CB_REGION='<地域>' CB_USER='<账号>' CB_PASS='<密码>' node seed-exhibits.cjs
```

> ⚠️ 密码走环境变量，**别把密码写进脚本或提交到 git**。用完删除脚本，或确保它在 `.gitignore` 内。

```js
// seed-exhibits.cjs —— 一次性种子脚本，用完即删
const store = new Map()
globalThis.localStorage = {
  getItem: (k) => (store.has(k) ? store.get(k) : null),
  setItem: (k, v) => store.set(k, String(v)),
  removeItem: (k) => store.delete(k),
  clear: () => store.clear(),
  key: (i) => [...store.keys()][i] ?? null,
  get length() { return store.size },
}
globalThis.window = globalThis.window || globalThis
globalThis.self = globalThis.self || globalThis
globalThis.navigator = globalThis.navigator || { userAgent: 'node' }

// 基于 Node 全局 fetch 的最小 XMLHttpRequest 垫片
class XHRShim {
  constructor() {
    this.readyState = 0; this.status = 0; this.statusText = ''
    this.responseText = ''; this.response = ''; this.responseType = ''
    this.withCredentials = false; this.timeout = 0; this.upload = {}
    this._headers = {}; this._listeners = {}
    this.onreadystatechange = this.onload = this.onerror = this.ontimeout = null
  }
  open(m, u) { this._method = m; this._url = u; this.readyState = 1; this._fire('readystatechange') }
  setRequestHeader(k, v) { this._headers[k] = v }
  getResponseHeader(k) { return this._resHeaders ? this._resHeaders.get(String(k).toLowerCase()) : null }
  getAllResponseHeaders() { return this._rawHeaders || '' }
  addEventListener(t, fn) { (this._listeners[t] ||= []).push(fn) }
  removeEventListener(t, fn) { this._listeners[t] = (this._listeners[t] || []).filter((f) => f !== fn) }
  abort() { this._aborted = true }
  _fire(t) {
    const on = this['on' + t]
    if (typeof on === 'function') on.call(this, { type: t })
    for (const fn of this._listeners[t] || []) fn.call(this, { type: t })
  }
  send(body) {
    const opts = { method: this._method || 'GET', headers: this._headers }
    if (body != null) opts.body = body
    let to, ctrl
    if (this.timeout) { ctrl = new AbortController(); opts.signal = ctrl.signal; to = setTimeout(() => ctrl.abort(), this.timeout) }
    fetch(this._url, opts).then(async (res) => {
      if (to) clearTimeout(to)
      this.status = res.status; this.statusText = res.statusText || ''
      this._resHeaders = res.headers
      let raw = ''; res.headers.forEach((v, k) => { raw += `${k}: ${v}\r\n` }); this._rawHeaders = raw
      const txt = await res.text()
      this.responseText = txt
      this.response = this.responseType === 'json' ? (() => { try { return JSON.parse(txt) } catch { return null } })() : txt
      this.readyState = 4; this._fire('readystatechange'); this._fire('load')
    }).catch((err) => {
      if (to) clearTimeout(to)
      this.readyState = 4; this._fire(err && err.name === 'AbortError' ? 'timeout' : 'error')
    })
  }
}
globalThis.XMLHttpRequest = globalThis.XMLHttpRequest || XHRShim

// —— 要插入的展品（按需改）——
const EXHIBITS = [
  { exhibitId: 'exhibit-001', name: '中华白海豚', category: '旗舰物种', summary: '北部湾海域的“水上大熊猫”，国家一级保护动物', text: '……讲解词……' },
  // 继续加……
]

;(async () => {
  const mod = require('@cloudbase/js-sdk')
  const cloudbase = mod.default || mod
  const app = cloudbase.init({ env: process.env.CB_ENV, region: process.env.CB_REGION || 'ap-shanghai' })
  const { error } = await app.auth.signInWithPassword({ username: process.env.CB_USER, password: process.env.CB_PASS })
  if (error) throw new Error('登录失败：' + (error.message || JSON.stringify(error)))
  console.log('登录成功：' + process.env.CB_USER)

  const col = app.database().collection('exhibits')
  for (const e of EXHIBITS) {
    const existing = await col.where({ exhibitId: e.exhibitId }).count()
    if (existing.total > 0) { console.log('跳过（已存在）：' + e.exhibitId); continue }
    const res = await col.add({ ...e, images: [], image: '', audioUrl: '', videoUrl: '' })
    console.log('已插入：' + e.exhibitId + '  _id=' + (res.id || JSON.stringify(res)))
  }
  const after = await col.count()
  console.log('\n当前 exhibits 集合总数：' + after.total)
  process.exit(0)
})().catch((err) => { console.error('[FAIL]', err && err.message ? err.message : err); process.exit(1) })
```
