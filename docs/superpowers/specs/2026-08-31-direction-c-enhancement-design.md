# 方向 C：均衡改善路线 — 设计文档

**日期**：2026-08-31  
**项目**：北部湾海洋生态守护站讲解（微信小程序 + 后台管理）  
**背景**：小程序主要用于线下现场导览，访客以中小学生和普通游客为主，客户目标是科普教育 + 互动体验并重。

## P0：媒体三件套改进

### 文字介绍

- 排版优化：段落间距、首行缩进，长文可读性提升
- 折叠展开：超过 5 行自动折叠，显示"展开全文"按钮
- 字号调节：右上角 A⁻ / A⁺ 按钮，可调节三档字号，偏好存入本地存储

### 音频播放器

- 进度条：可拖拽 / 点击跳转，显示当前时间 / 总时长（格式：mm:ss）
- 快进快退：±10 秒按钮
- 加载状态：显示"加载中…"，加载失败显示友好错误提示
- 切页自动暂停：离开 exhibit 页时音频停止

### 视频播放器

- 封面预览：展开前显示封面图（复用 `images[0]`），点击后才渲染 `<video>`
- 时长提示：显示"约 X 分钟"（需后台录入，或前端估算）
- 网络提示：非 Wi-Fi 时提示"建议 Wi-Fi 下观看"
- 错误兜底：加载失败时显示友好错误信息

**改动文件**：`miniprogram/pages/exhibit/exhibit.wxml`、`exhibit.ts`、`exhibit.wxss`

## P1：展品列表搜索 + 分类筛选

### 小程序端

- 顶部搜索框：实时过滤展品名称（输入即生效）
- 分类标签行：横向可滚动的分类筛选芯片（全部 / 鱼类 / 珊瑚 / 哺乳类 / 贝类 / 藻类 / 其他）
- 搜索词 + 分类可叠加过滤
- 无结果时显示空状态提示

### 后台端

- 展品编辑页新增"分类"下拉选择字段（固定枚举：鱼类 / 珊瑚 / 哺乳类 / 贝类 / 藻类 / 其他）
- 现有展品 `category` 为空归入"全部"，向后兼容

### 数据模型

```ts
// Exhibit 新增字段
category?: string  // 'fish' | 'coral' | 'mammal' | 'shellfish' | 'algae' | 'other'
```

**改动文件**：`miniprogram/pages/list/list.wxml`、`list.ts`、`list.wxss`；`admin/src/views/ExhibitEditView.vue`；`admin/src/types/exhibit.ts`；`miniprogram/models/exhibit.ts`

## P2：轻量打卡进度

### 行为

- 进入展品详情页（`onLoad`）时自动写入"已看"记录，无需用户操作
- 数据存入微信本地存储（`wx.setStorageSync`），键名 `visited_exhibits`，值为 exhibitId 数组

### 展示

- 展品列表顶部：进度文字"已参观 X / Y"+ 进度条
- 展品卡片：已参观的卡片右上角显示绿色 ✓ 标记
- 展品详情页底部：显示"✅ 已参观"标记

### 约束

- 本地存储，无需登录，无后端改动
- 换设备 / 清缓存会重置（对线下一次性参观场景可接受）

**新增文件**：`miniprogram/utils/visitHistory.ts`（封装读写打卡记录）  
**改动文件**：`list.wxml`、`list.ts`、`exhibit.ts`

## P3：分享功能

### 层次 1 — 分享给朋友/群（必做）

- 配置 `onShareAppMessage`：标题为展品名称，imageUrl 为封面图，path 携带 `exhibitId`
- 配置 `onShareTimeline`（分享到朋友圈）：同上
- 展品详情页底部新增分享按钮（可选，微信右上角菜单本身也支持）

### 层次 2 — 生成分享卡片保存到相册（选做）

- 用 Canvas 2D 绘制：展品大图 + 名称 + 摘要前 60 字 + 站名 + 小程序码
- `wx.canvasToTempFilePath` 转图片后 `wx.saveImageToPhotosAlbum` 保存
- 触发入口：展品详情页底部"保存卡片"按钮

**改动文件**：`exhibit.wxml`、`exhibit.ts`、`exhibit.wxss`  
**新增文件**（层次 2）：`miniprogram/utils/shareCard.ts`

## 验证方式

1. 微信开发者工具模拟器逐页验证各功能
2. 音频：加载、播放/暂停、拖拽进度、±10s、离页暂停
3. 视频：封面显示、点击展开播放、错误提示
4. 搜索：输入关键词实时过滤；切换分类；组合过滤；无结果提示
5. 打卡：进入展品页后返回列表确认 ✓ 出现，进度数字正确
6. 分享：onShareAppMessage 预览图和标题正确，点开链接跳到正确展品
