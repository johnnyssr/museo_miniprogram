# 展品数据上云（第一阶段：只做读通路）设计文档

日期：2026-07-13
状态：已确认

## 目标与范围

把展品数据从小程序本地 mock 迁移到微信云开发：数据存云数据库，小程序通过**云函数**读取展示。

**本阶段只做「读」**：
- 展品数据存云数据库集合 `exhibits`。
- 一个云函数 `getExhibits` 提供查询（单个 / 全部）。
- 小程序改造 service 层，从云函数读数据（页面渲染逻辑不动）。
- 初始 3 条数据在云开发控制台**手动录入**。

**本阶段明确不做**（留待后续阶段）：
- 内容管理后台（增删改查展品）——第二阶段。
- 写 / 改 / 删、云函数鉴权（读的是公开数据，无需鉴权）。
- 「按展品生成小程序码」的实现——已采纳小程序码方案（微信扫、小程序内扫都能跳），但生成实现放到读通路跑通之后；本阶段仅在设计上预留 `exhibitId` 启动参数。

## 一、数据模型（云数据库集合 `exhibits`）

每个文档字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `_id` | string | 云数据库主键（自动或手动） |
| `exhibitId` | string | 展品业务编号，二维码里编码的值（如 `exhibit-001`） |
| `name` | string | 名称 |
| `dynasty` | string | 年代（可选） |
| `image` | string | 图片地址，兼容 `cloud://` 或 `https://` |
| `text` | string | 文字介绍 |
| `audioUrl` | string | 语音地址，兼容 `cloud://` 或 `https://` |
| `videoUrl` | string | 视频地址，兼容 `cloud://` 或 `https://` |

**要点：**
- 二维码 / 详情页使用 `exhibitId`（业务编号），与数据库 `_id` 解耦；查询按 `exhibitId`。
- 媒体字段存字符串，同时兼容 `cloud://`（云存储文件 ID）和 `https://`（外部链接）。第一阶段先用现有 http 外链；将来媒体无论进云存储还是走外部平台接口，数据模型与小程序代码都不用改。

## 二、云函数 `getExhibits`

位置：`cloudfunctions/getExhibits/`

- 入参可选 `exhibitId`：
  - 传 `exhibitId` → 查询并返回单个展品（详情页用）。
  - 不传 → 返回全部展品（列表页用）。
- 从 `exhibits` 集合查询，返回结果给小程序。

## 三、小程序改造（只改 service 层与调用点）

- `app.ts`：初始化云开发 `wx.cloud.init({ env: '<envId>' })`（envId 由用户在开发者工具开通云开发后提供）。
- `models/exhibit.ts`：`Exhibit` 接口新增 `exhibitId` 字段，其余不变。
- `services/exhibit.ts`：
  - 删除本地 `EXHIBITS` 数组及媒体常量。
  - `getExhibitById(id)` 和 `getAllExhibits()` 改为**异步**，内部调用 `wx.cloud.callFunction({ name: 'getExhibits', ... })`。
- 调用点改造：详情页 `onLoad`、列表页 `onLoad` 改为 `await` / `.then` 处理异步结果。

**要点：** 页面渲染逻辑、wxml、wxss 均不改动，只是数据来源从「同步读本地」变为「异步调云函数」。这验证了数据访问收敛在 service 层的价值。

## 四、错误处理

- 云函数调用失败（网络 / 超时）：页面 catch 后 `wx.showToast('加载失败，请重试')`，显示空状态而非崩溃。
- 详情页查无此 `exhibitId`：云函数返回空，页面显示现有「未找到该展品」空状态。
- 列表返回空数组：显示现有「暂无展品」空状态。
- 加载期间：`wx.showLoading`，加载完 `wx.hideLoading`。

## 五、测试策略（手动验证）

1. 云开发控制台确认 `exhibits` 集合有 3 条数据。
2. 开发者工具编译 → 列表页从云函数拉到 3 张卡片。
3. 点卡片 / 模拟扫码 `exhibit-001` → 详情页正确显示对应展品。
4. 断网或输错 envId → 页面 toast 报错、不崩溃。
5. 详情页图文 / 音 / 视频照常显示（媒体仍是现有 http 外链）。

## 六、依赖用户的账号操作（非写代码）

- 在微信开发者工具开通云开发，获取 **envId**（提供给开发者填入 `app.ts`）。
- 建立 `exhibits` 集合，手动录入 3 条数据（将提供逐字段录入清单）。
